# Elitium ERP

ERP web para gestão comercial, desenvolvido como TCC na FIAP School.

🌐 **Site do projeto:** https://sudrescodes.github.io/Elitium-Site/

## Funcionalidades
- Vendas, orçamentos, compras e clientes
- Estoque com alertas Crítico/Atenção/OK
- Financeiro, relatórios e analytics com gráficos
- Previsão de demanda
- Notificações Web Push e assistente de IA
- Interface em português e inglês, com visual escuro "chrome metálico"
- Exportação de PDF/CSV

## Stack
Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · Recharts · PostgreSQL 16 + Prisma · JWT (access + refresh rotativo, cookies HttpOnly, CSRF, rate limit) · next-intl · Groq (IA) · Zod · Web Push (VAPID) · Sentry · Jest · GitHub Actions · Render

## Meu papel
Desenvolvi o sistema: front-end e API (`/api/v1`), banco com Prisma, autenticação com JWT/refresh token e CSRF, exportação de PDF/CSV, dashboard com gráficos, health-check/métricas e deploy contínuo. Também ajudei na apresentação, no marketing e em outras partes do TCC.
